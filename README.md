# Sony ARW 全套新创意外观 (Creative Look) 解锁与机型伪装工具库

本项目通过逆向分析索尼 **Imaging Edge Desktop (IED)** 工具（`/Applications/Imaging Edge/Edit.app`）对索尼 **ARW (RAW)** 文件的底层加密机制与创意外观列表生成逻辑，实现了将 **A7C II (ILCE-7CM2)**、**A7 IV** 等机型的 RAW 照片在保持 100% 结构完整与原厂传感器标定的前提下，**一次性全套解锁并写入索尼新相机的所有创意外观**（包含 **FL2 怀旧胶片**、**FL3 清透电影胶片** 等）。

## 🚀 快速使用

### 1. 单张照片一次性全套解锁
```bash
python3 camouf_arw.py /path/to/DSC00506.ARW
```
> 输出：`DSC00506_all_looks.ARW`

### 2. 批量处理整个相册目录
```bash
python3 camouf_arw.py /path/to/raw_folder/ -o /path/to/output_folder/
```

### 3. 可选参数
- `-l, --look {fl2, fl3, fl, vv2, in, sh, ...}`：指定打开该 ARW 时的默认预选外观（默认: `fl2`）
- `-t, --target {a7c2, a7m5, a1m2, ...}`：机型伪装（默认: `a7c2`，保持原厂传感器标定）

## 🛠️ 逆向核心原理简析

1. **SR2SubIFD 密文注入**：
   相机在拍摄写入 RAW 时，将支持的外观列表存放在私有加密数据块 `SR2SubIFD` 中（密钥 `0x44332211`）。
2. **零位移重加密 (Zero-Shift Re-encryption)**：
   解密 `SR2SubIFD`，原位将新一代胶片外观（`FL2`、`FL3`）写入列表，重加密后原位写回。
3. **100% 结构无损**：
   文件长度与 RAW 像素切片偏移 100% 保持原样，Sony 官方 Edit.app 原生无缝打开与渲染。
